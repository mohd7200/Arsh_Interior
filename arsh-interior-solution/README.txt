Arsh Interior Solution website

Open index.html in a browser to view the site.

Add a project photo: put the image in the images folder, then add an entry
to the PROJECTS list in js/script.js, for example:
{cat:"kitchen", title:"Project name", desc:"Short description", img:"images/my-photo.jpg"}
Categories: kitchen, ceiling, bedroom, tv, furniture, home.
(To add a new category, also add it to CATS and ICON in js/script.js.)

Contact form: opens WhatsApp (919910340178) with the details. To use a form
service instead, edit f.onsubmit in js/script.js.

Upload the whole folder to any web host (Netlify, Hostinger, cPanel) to publish.
